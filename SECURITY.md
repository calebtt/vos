# Security Policy
VOS is pre-1.0; only the `main` branch is supported.
## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private reporting ("Security" tab → "Report a vulnerability") on calebtt/vos. Include steps to reproduce, affected commit, and impact. Expect an acknowledgement within 7 days.
## Scope
VOS's own code (session, actuator, ipc, vtb-sdk, image build scripts). Bugs in GrapheneOS/AOSP should go to those projects.
## Never post
API keys, device serials, logs containing personal voice turns, or recordings.
