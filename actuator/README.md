# actuator — `com.vos.actuator`

Trusted base: sensors and hands, **no `INTERNET`** (TARGET-PLAN §3.1, §5.2).

- `ActuatorService` — the session's Binder entry (`IVosActuator`, from `:ipc`), guarded by the `com.vos.permission.SESSION` signature permission and by `BinderGuard` before any argument is read: exact caller package, the actuator's own signing cert, the grant table; refusals are audited to `files/audit/audit.jsonl` (§5.3, M1-AUTH-01). The session reports `turnReady` and `endTurn` here.
- `AudioPlane` — the one owner of what is heard and who holds the mic (§3.3). M1 skeleton: IDLE → CAPTURE (summon: pause playing media through its MediaController, transient focus, `MODE_IN_COMMUNICATION`, communication device = a headset if connected, else the speaker) → CONVERSE (the session's backend is ready) → RESTORE (mode, communication device, focus; resume media only if this turn paused it and the owner didn't pause it during the turn; re-pause a player that resumes itself) → IDLE. One audit line per transition (`{state, focus, mode, inDev, outDev, pausedPkg, mixes, turnId, reason}`); refused operations are audited too. A summon during a call is refused (HOLD's offline-only summon comes with the offline grammar). NOTICE, ANNOUNCE and APP_ASSIST are declared for M2/M4. `AndroidAudioPlatform` is its AudioManager/MediaSession side; media control needs the notification listener enabled.
- `TurnService` — the open turn, as a `microphone` foreground service. `VoiceTurn` captures 16 kHz mono (`VOICE_COMMUNICATION`, platform AEC and NS when available) into the mic pipe from the summon on, plays the session's reply from the speaker pipe as `USAGE_ASSISTANT` on the communication device, and on stop releases the mic first (logged as `AudioRecord.release … ms=`), then silences playback. A turn ends on the owner's stop (tile, notification), the session's `endTurn`, the session dying, an I/O error, or a 10-minute cap.
- `SummonTile` — the Quick Settings tile: summon, or stop the open turn. Exported only to the system (`BIND_QUICK_SETTINGS_TILE`, enforced by the policy check).
- `DebugSummonActivity` (debug builds only, `src/debug`) — a summon the shell can start (guarded by `DUMP`); it can swap the mic for `files/debug/mic-inject.pcm` and the speaker for `files/debug/speaker-<turnId>.pcm`, so turns are tested without speaking or sound. Listed in `ci/exported-components-actuator-debug.txt`, which the release APK never gets.
- `HandsService` (AccessibilityService) and `NotificationsService` (NLS) — stubs, exported but guarded by the system-only `BIND_ACCESSIBILITY_SERVICE` / `BIND_NOTIFICATION_LISTENER_SERVICE` permissions, so only the system can bind them (M1). `ci/policy_check.py` fails any exported service with one of these actions that lacks its guard.
- The manifest strips `INTERNET` with `tools:node="remove"`; `ci/policy_check.py` checks the built APK anyway.
- Depends on `:vtb-sdk` (the actuator hosts the VTB registry, §3.4) and `:ipc` (the session ↔ actuator contract).

Tests: `./gradlew :actuator:testDebugUnitTest` (`AudioPlaneTest`) and `:ipc:testDebugUnitTest` (`BinderGuardTest`, `PeerLinkTest`); on a device, `eval/m1/auth-01.sh` (M1-AUTH-01) and `eval/m1/turn-pipes.sh` (turn pipes, #240).
