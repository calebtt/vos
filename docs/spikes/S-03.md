# S-03 — `ro.control_privapp_permissions=enforce` accepts the VOS allowlist (#12)

**Needed by:** M0 (M0-04, #129). **Device:** Phone B (`panther`) on the S-01 hello image. Plan: TARGET-PLAN §6.0, §4.4 step 3.

## Claim
`ro.control_privapp_permissions=enforce` on Graphene accepts the VOS allowlist from `/product/etc/permissions`.

## Procedure
1. On the S-01 image: `adb shell getprop ro.control_privapp_permissions` → expect `enforce`.
2. Boot with `/product/etc/permissions/privapp-permissions-vos.xml` listing exactly the permissions the hello priv-app requests.
3. `adb logcat -b all -d | grep -i 'privapp\|Privileged permission'` — no "not in privapp-permissions allowlist" lines; system_server did not crash-loop.
4. `adb shell dumpsys package com.vos.hello` — every allowlisted permission granted.
5. Negative leg: request one extra privileged permission not in the XML; confirm enforce mode refuses to boot or logs the violation (record which).

## Pass criteria
system_server boots; no allowlist exceptions.

## Fallback
Move a permission to a different partition XML.

## Result: PARTIAL (read-only checks, 2026-10-18)
Phone B = Pixel 7 `panther` (serial ending E4, SKU GVU6C), official GrapheneOS build `CP3A.261005.002.A1` / incremental `2026100601` (Android 17, SDK 37, patch 2026-10-05), bootloader `cloudripper-17.0-15902555`, `ro.boot.flash.locked=1`, `verifiedbootstate=yellow`, `vbmeta.device_state=locked`, active slot `_b`, sandboxed Play installed (`com.google.android.gms`, `com.android.vending`).

- `getprop ro.control_privapp_permissions` = **`enforce`** on stock Graphene panther (step 1 confirmed on the base build).
- `/product/etc/permissions` already holds privapp XMLs on Graphene (e.g. `privapp-permissions-google-p.xml`, `app.grapheneos.apps.xml`), so the product partition is a live allowlist location.
- `logcat -b all -d | grep -i privapp`: no allowlist violations on the current boot (the only hit was our own adb getprop line).
- Steps 2–4 (VOS allowlist XML on the S-01 image, negative leg) need the S-01 image, so they wait for the unlock and flash.
